# Storage

## Че делает
Низкоуровневая работа с файловой системой. Чистая работа с байтами.
Сохраняет массивы байт в файлы на диске и читает их обратно по физическому адресу.

### Вход:
Массив байт `std::vector<uint8_t>)`, имя БД, имя таблицы
### Выход:
1) запись: `RecordId` - физический адрес в файле
2) чтение: Считанный массив байт по `RecordId`


# PARSER

## Че делает
Преобразование сырого текста SQL -запроса во внутреннее представление - абстрактное синтаксическое дерево AST.

Просто парсит входящий текст, проверяет грамматику и раскидывает слова по структурам.


### Вход:
`std::string`
### Выход:
`std::unique_ptr<ASTNode>` - указатель на корень AST дерева


# Index Деревце :))))

## Че делает
`B*` дерево. Индекс связывает конкретное значение ключа с физическим адресом строки на диске(`RecordId`).



# Executor

## Че делает
Принимает AST дерево от парсера, проеряет семантику(существуют ли таблицы, совпадают ли типы)
Упаковывает данные в байты

### Вход:
`ASTNode` от парсера
### Выход:
Результат операции.
`SELECT` - JSON
`INSERT/UPDATE` - статус выполнения



# Core

## Че делает
Хранит базовые структуры данных, константы, исключения, которые нужны во всем проектике.
Чтоб общие зависимости хранились в одном месте.


# Catalog

## Че делает
Хранит информацию о структуре базы данных:
1. какие существуют базы
2. какие у них таблицы
3. какие у таблиц колонки
4. типы колонок и ограничения
